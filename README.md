# Insight Graphics — website wireframe

Single-page wireframe for Insight Graphics (labels, packaging and commercial print, Kolkata).

- `index.html` — the whole page; open it directly or serve the folder.
- `assets/` — logos, icons and photos (originals; most are also inlined in the page).
- `figma-export/` — static 1440px snapshot and the script that builds it for Figma import.

Toggle **Notes** (bottom-left) on the page to highlight copy and images that are still placeholders.
